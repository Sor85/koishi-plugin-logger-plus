# 01 — 提取日志身份共享 module，收口跨端身份与游标语义

**What to build:** 日志身份的值语义（身份编码、记录先后比较、游标编码/解析、「是否早于游标」判定）收口为一个纯 module，客户端与服务端共享同一份实现。身份编码与游标编码成为同一个函数，跨 JSON 边界的游标契约不再靠两份实现人工对齐。用户可见行为不变：渲染标识、去重、视口锚点与分页结果都与现在一致，已发出的分页游标格式不变。维护者改身份或游标规则只改一处，并有行为测试锁定。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 新增日志身份 module，集中身份编码、记录先后比较、游标编码与解析、「是否早于游标」判定；身份编码与游标编码是同一个函数，客户端生成的游标与服务端理解、回传的游标天然同口径。
- [ ] module 使用结构类型（时间戳与序号两个字段），不依赖客户端或服务端各自的日志记录类型；沿用「`src` 下纯 module 被客户端跨目录 import 且供服务端使用」的既有先例。
- [ ] 客户端身份与合并 module 改为消费共享 module 的身份编码与先后比较；渲染标识、视口锚点、去重与截断行为不变，合并去重与记录截断仍留在原处只消费共享语义。
- [ ] 服务端日志归档改为消费共享 module 的身份/游标编码、先后比较、游标解析与「是否早于游标」判定；分页、筛选、早停、读取容错与事件契约不变，数组排序包装仍留原处只消费共享次序。
- [ ] 保持现有游标 wire 格式不变，已发出的分页游标继续有效；缺失游标从最新日志开始读取。
- [ ] 非法游标以显式判断处理，保持现有可观察结果（返回空页），不再依赖 `NaN` 比较的偶然行为，也不因异常输入返回全部历史。
- [ ] 先完成提取并让客户端身份/合并与服务端日志归档的既有行为测试原样跑绿当搬运护栏，再改为消费共享语义。
- [ ] 通过日志身份 module 的公开 interface 补齐并断言：同一记录同一标识、不同记录标识不同、同时间戳按序号排序、跨重启序号回绕仍按时间戳主导、游标编码→解析往返回到同一身份、缺失游标从最新开始、非法游标得到明确空结果、早于/等于/晚于游标判定正确。测试不挂载组件、不启动插件、不断言源码文本。
- [ ] 替换日志视图测试中锁定身份编码与渲染标识源码字符串、且已被共享 module 行为测试覆盖的断言；两端调用同一函数的一致性由构造保证，保留一条断言编码格式稳定的测试即可。
- [ ] 下层文件清单、倒序读取与筛选编译 module 及其它无关测试保留不删。
- [ ] 运行项目测试、可用的类型检查与项目构建并记录结果；说明类型检查的实际命令与范围，不把前端打包等同于服务端类型检查，不主动运行浏览器测试。

## Execution constraints

本工单是行为不变的值语义收口，不改变游标格式、事件契约、排序方向或身份构成。不引入通用编码框架、可插拔序列化、UUID 或数据库主键等替代身份方案；不改分页生命周期、历史读取、文件策略或客户端展示。不使用 subagent 做实现，代码实现由主 Agent 完成；不创建分支、不自行提交。
