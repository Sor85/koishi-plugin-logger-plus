# 01 — 接通非日期日志会话与可靠分页

**What to build:** 无日期模式下，用户仍能查看实时日志、按插件/等级/关键词筛选，并手动加载更早记录；这些行为统一由日志会话 module 管理。跨筛选保留共享历史缓存，第一页与后续页遵循一致的加载、结束、失败重试和过期响应规则，前插不打断阅读位置。

**Blocked by:** None — can start immediately

Status: ready-for-agent

## Acceptance criteria

- [ ] 纯 TypeScript 日志会话 module 接入实际非日期浏览路径；Vue adapter 只负责响应式、意图转交和生命周期接线，Console adapter 复用既有请求 seam。必要的迁移准备随本工单完成，不仅交付一个未被页面使用的核心。
- [ ] 无筛选进入仍优先显示实时数据，不自动读取磁盘历史；点击“查看更多消息”才加载更早记录。实时数据来源、手动加载策略及 UI 外观保持不变。
- [ ] 插件、等级、关键词与插件名称/标签匹配继续沿用现有筛选规则，保留现有搜索防抖。等价查询不因派生数组引用变化而重复请求。
- [ ] 非日期共享历史缓存跨筛选保留；切换查询重置分页进度并重新获取所需第一页，当前展示始终按新条件过滤。清除筛选后仍可展示先前加载的共享历史。
- [ ] 实时、缓存与历史页按既有身份规则去重并维持顺序；不接管或复制全局实时日志存储。
- [ ] 第一页与后续页共用当前查询的加载裁决；第一页在途或重复点击时不会并发请求同一查询的下一页。新查询不必等待旧查询结束。
- [ ] 第一页返回的游标与 hasMore 成为会话状态；到达末尾后不再允许继续分页，后续页使用服务端返回的当前查询游标。
- [ ] 未建立游标时，无筛选浏览使用正确的加载起点；新筛选必须从正确第一页建立进度，不能因共享缓存已有较早记录而跳过尚未扫描的区间。
- [ ] 查询切换使旧请求失效：旧请求成功、失败或结束均不能修改当前记录、缓存、游标、加载状态或错误提示。覆盖第一页和后续页在途时切换筛选。
- [ ] 当前第一页失败时保留符合当前条件的实时与缓存记录，提示失败并允许重试第一页，不沿用上一查询游标；后续页失败保留已有记录与游标，允许重试同一逻辑页。失败不得被当成正常结束。
- [ ] 历史前插继续经过既有 LogViewport around 行为保护位置；日志会话不持有锚点或滚动算法，不改 LogViewport interface 与核心。
- [ ] 补充通过日志会话公开 interface 驱动的行为测试，以可控请求 adapter 验证重复触发、响应乱序、失败重试、分页结束、共享缓存和合并结果，不读取私有状态或匹配实现源码。
- [ ] 补充非日期前插及查询切换交叠的视口协作测试，复用现有 LogViewport 测试 seam，不新增 DOM seam。
- [ ] 日期查询暂时保留原有可用路径，非日期迁移不破坏日期浏览。尚未迁移的卸载入口能够通过日志会话意图清空非日期历史并使请求失效，不直接写入其私有状态，也不提前接管日期分页。
- [ ] 保留现有服务端分页、视口和未迁移日期路径的测试；仅替换已由本工单行为测试覆盖的源码字符串断言。在关键异步提交点注释请求有效性与前插顺序。
- [ ] 运行项目测试、可用类型检查和项目构建并记录结果；不把前端打包等同于完整 Vue 类型检查，不主动运行浏览器测试。

## Execution constraints

本工单是日志会话规格的第一条纵向切片。实现后非日期路径可独立验证，日期路径保持原样可用。不推进服务端归档提取或跨端身份重构，不改协议、UI 外观或视口核心。不使用 subagent，不创建分支、不自行提交。
